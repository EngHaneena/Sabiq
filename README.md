## 📌 عن المشروع
يواجه طلاب وخريجو علوم الحاسب وهندسة البرمجيات تشتتاً مستمراً عند اختيار التقنيات والمسارات الوظيفية؛ حيث تعتمد أغلب النصائح على آراء فردية عامة[cite: 2]. يهدف **"سابق"** إلى تحويل البيانات الضخمة إلى قرارات مهنية واضحة، مع تقديم توقع مالي دقيق وخطة عمل مؤتمتة بضغطة زر[cite: 2].

---

## ✨ أبرز المميزات (Key Features)

1. **معالجة البيانات والواجهة التفاعلية (Interactive Data Pipeline):**
   * فلترة البيانات الضخمة لأكثر من 76 ألف سجل لاستخراج الرواتب، المسارات، وسنوات الخبرة[cite: 1, 2, 4].
   * واجهة تفاعلية مرنة مبنية بـ `ipywidgets` لاختيار المسار الوظيفي وعرض تحليله فورياً[cite: 2, 4].

2. **مصفوفة المهارات البصرية (Visual Skill Matrix):**
   * تحليل التقنيات الأكثر طلباً وربطها بمتوسط الرواتب السنوية[cite: 1, 2, 4].
   * إنتاج إنفوجرافيك ذكي ملون بنظام الأرباع (`skill_matrix.png`) يوضح المهارات الإلزامية للتوظيف والمهارات النوعية المضاعفة للدخل[cite: 1, 2, 4].

3. **التنبؤ المالي بالذكاء الاصطناعي (Machine Learning Pipeline):**
   * تدريب نموذج انحدار غابات عشوائية (`RandomForestRegressor`) عبر مكتبة `scikit-learn`.
   * تقييم دقة النموذج بمقاييس معيارية: $R^2$ Score، ومتوسط الخطأ المطلق (MAE)، ونسبة التنبؤات المقبولة ضمن هامش خطأ ±20%.
   * حساب وزن وأهمية كل تقنية في رفع القيمة السوقية (`Feature Importance`).
   * توفير محاكي حي لتوقع الراتب السنوي التقديري بناءً على المهارات وسنوات الخبرة.

4. **أتمتة العرض التقديمي وخارطة الطريق (Automated Presentation Deck):**
   * توليد عرض تقديمي متكامل من 5 شرائح بصيغة PowerPoint (`career_roadmap.pptx`) بتصميم داكن احترافي عبر `python-pptx`[cite: 1, 4].
   * دمج نتائج الإنفوجرافيك، وتحليلات الذكاء الاصطناعي، وخطة عمل مرحلية، وترشيح أهم الدورات والشهادات العالمية المعتمدة لكل مهارة[cite: 1, 4].
